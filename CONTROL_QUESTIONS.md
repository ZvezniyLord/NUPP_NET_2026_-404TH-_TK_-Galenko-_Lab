# Контрольні запитання — короткі відповіді

## 1. Класи, структури, value та reference типи

Клас — користувацький reference type, екземпляр якого зазвичай розміщується в керованій купі, а змінна зберігає посилання на об'єкт. Структура (`struct`) — value type: значення копіюється при присвоєнні та передаванні без `ref`/`out`/`in`. Клас підтримує наслідування від іншого класу; структура не може наслідуватися від іншої структури або класу, але може реалізовувати інтерфейси. Value type містить саме значення, reference type — посилання на об'єкт.

## 2. Абстрактний клас

Абстрактний клас позначається `abstract` і не може бути безпосередньо створений через `new`. Він може містити поля, властивості, конструктори, звичайні реалізовані методи й абстрактні методи без реалізації. Звичайний клас можна інстанціювати, якщо його конструктор доступний.

## 3. Інтерфейс і відмінність від абстрактного класу

Інтерфейс задає контракт: набір членів, які повинен реалізувати тип. Клас може реалізувати багато інтерфейсів, але наслідуватися лише від одного базового класу. Абстрактний клас може зберігати стан у полях, мати конструктори та спільну реалізацію; інтерфейс переважно описує можливості типу і не використовується як базовий об'єкт зі станом.

## 4. Наслідування і модифікатори доступу

Наслідування дозволяє похідному класу повторно використовувати та розширювати члени базового класу. Основні модифікатори доступу C#: `public`, `private`, `protected`, `internal`, `protected internal`, `private protected`, а також `file` для типів на рівні файла.

## 5. Статичні поля та методи

Статичний член належить типу, а не конкретному екземпляру. Для нього не потрібно створювати об'єкт: `TypeName.Member`. Звичайне поле або метод належить конкретному екземпляру і доступне через об'єкт. Статичні методи не мають посилання `this` і напряму не можуть звертатися до нестатичних членів без екземпляра.

## 6. Делегати та їх види

Делегат — типобезпечне посилання на метод із визначеною сигнатурою. Він може містити один або кілька методів (multicast delegate) і часто використовується для подій та callback-функцій. Делегати бувають користувацькі та вбудовані узагальнені: `Action` (без результату), `Func` (повертає значення), `Predicate<T>` (повертає `bool`).
