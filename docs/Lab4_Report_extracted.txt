Лабораторна робота №4
Розробка вебсерверів засобами ASP.NET Core Web API

Проєкт MusicContest.REST. Дві сутності: Songs і Performances. Трирівнева архітектура: контролери,
CRUD-сервіс, репозиторій і SQLite.
