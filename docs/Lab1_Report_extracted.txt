 Мета роботи
 Закріпити основи об'єктно-орієнтованого програмування в C#: створення класів та об'єктів,
 наслідування, поліморфізм, статичні члени, делегати, події, методи розширення та
 узагальнений CRUD-сервіс. Додатково реалізувати збереження й відновлення даних у форматі
 JSON.


 Реалізовані складові
  Складова                   Реалізація

  Модель предметної          Абстрактний клас ContestParticipant та похідні класи SoloSinger і VocalGroup;
  області                    моделі Song та Performance.

  Основи ООП                 Конструктори, властивості, наслідування, перевизначення методів і
                             поліморфізм.

  Статичні члени             Статичне поле, статичний конструктор і статичний метод для підрахунку
                             створених об'єктів.

  Події та делегати          Делегат ScoreChangedHandler і подія ScoreChanged для відстеження зміни оцінки
                             виступу.

  Generic CRUD               Операції Create, Read, ReadAll, Update та Remove для типів, що реалізують IEntity.

  JSON                       Методи Save та Load для серіалізації й десеріалізації даних.
